# model/APWCS: XD bridge analysis

Source commit: `2fff83ab856417cc805fad44b55e68dc820fd03e`. All root source files remain unchanged. `xd_experiment/branch.py` loads only this checkout's own source by absolute path and checks SHA-256 before use. Checksums normalize **only CRLF to LF** for portability across Git checkout settings; all other bytes remain guarded. No UCFSHT implementation is imported or copied into the APWCS bridge.

- Model: original `model.py:Model_V2_AllCNN`, real feature dimension passed to constructor. Existing architecture uses gated Conv1d and average-pooling; the `kernel_size=5` constructor parameter does not replace the hardcoded Conv3/Conv5 implementation.
- Loss: original `train.py:adaptive_hybrid_loss` uses BCE for larger errors and **0.5×MSE**, threshold 0.3, for smaller errors. It does not use the UCFSHT Huber branch.
- Confidence: APWCS training **actively** flips labels below confidence 0.5 and softens labels below 0.7. `generate_confidences()` therefore reuses `confidence.py:generate_confidence_scores`; supplying all ones would disable a component of APWCS and is not the default. Generation uses only train features and generated pseudo-labels.
- Pseudo selection: `train.sh` references `Unsup_labels/UCF_pseudo_labels_ng.npy`. The header of `pseudo_proto_dist_swap.py` explicitly says it generated that artifact and marks it frozen. The bridge chooses this generator and its executable `main()` settings: per-video standardization; Gaussian p=0.05; zscore; first5 prototype (`prototype_method='none'`); attraction 0.8, repulsion 0.7, iterations3; isolated abnormal length2; gap2; swap at ratio0.8. The prototype segment distances are set to zero in this source. Its plot is retained with output redirected to the new run directory.
- Provenance limit: README instructs generic `pseudo.py`, which has different attraction settings (1.0/0.5/5) and Gaussian smoothing. The branch does not prove which script produced an old checkpoint. The selected frozen generator is a documented new XD baseline; it is not asserted to exactly reproduce historical APWCS reported results. Do not select between generators by XD test AP.
- Input adapter: supplied runtime arrays are already true spatial-crop means `(T,D)`. A singleton **already-reduced** axis lets the original pseudo/confidence `mean(axis=1)` be an identity operation. No crop replication, padding, dimension inflation or temporal resampling occurs here. The real five-crop aggregation belongs to the common data code.
- ITA: only original `_split_prefix_suffix_video` and `_tta_update_one_video` definitions are AST-loaded to avoid root `test.py`/`dataset.py` import-time CLI parsing. Their signatures and bodies are unchanged. Defaults match `test.sh`: k5, q1, min_keep3, lr0.01, steps30. The shared runner resets the adapter for each video, fixes detector weights, and evaluates common prefix/suffix masks. Returned adapter stores original diagnostic records in `_xd_ita_debug`.
- Legacy defects deliberately retained: original ITA sends selected `(N,D)` clips through model's `(N,1,D)` path, and weight `(N,)` times loss `(N,1)` broadcasts to `(N,N)`. Margin and regularization are computed but not included in final loss. Correcting these would be a separate algorithm implementation experiment, not this XD I/O bridge.

Public API: `make_model(dimension)`, `train_epoch(loader, model, optimizer, epoch, device, accumulation_steps=1)`, `generate_pseudo(featuresTD, indexNx2, outputdir)`, **`generate_confidences(featuresTD, indexNx2, pseudo_labels, outputdir)`**, `make_adapter(dimension)`, `adapt_one_video(model, adapter, featuresTD_tensor, settings)`, `provenance()` and `verify_source()`. Constants `BRANCH` and `COMMIT` identify this checkout.

Required direct packages: NumPy, PyTorch, SciPy, scikit-learn, Matplotlib and tqdm. Root main/W&B are not imported. `provenance()` records original source hashes and settings; root source edits cause a clear failure until the reviewed hash contract is deliberately updated.
